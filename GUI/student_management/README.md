# 学生信息管理面板

## 功能说明

学生信息管理面板是一个用于管理已招募学生的UI界面，与recruit_panel和paper_management_panel保持相同的尺寸和风格。

## 使用方法

- **打开/关闭面板**: 按 `S` 键
- **查看学生详情**: 点击学生项目
- **收集论文**: 点击"收集所有论文"按钮

## 学生信息显示

每个学生项目显示以下信息：
- **学生姓名**: 学生的姓名
- **专业信息**: 专业、GPA、性格
- **招募天数**: 被招募了多少天
- **已产出论文**: 当前产出的论文数量
- **研究进度**: 当前论文的研究进度百分比
- **当前论文**: 正在研究的论文标题

## 论文研究系统

### 研究进度显示
每个学生显示当前正在研究的论文：
- **研究进度**: 0-100%的进度条显示
- **当前论文**: 显示正在研究的论文标题
- **研究速度**: 基于学生属性计算

### 研究速度计算
学生的研究速度基于以下属性：
- **GPA**: 越高研究越快
- **潜力等级**: 高(2.0x)、中(1.5x)、低(1.0x)
- **性格**: 勤奋(+1.5)、创新(+1.0)、严谨(+0.5)、合作(+0.8)、独立(+0.7)
- **健康状况**: 优秀(1.3x)、良好(1.0x)、一般(0.7x)

### 进度颜色标识
- **绿色**: 接近完成 (≥80%)
- **黄色**: 进行中 (50-80%)
- **橙色**: 刚开始 (20-50%)
- **红色**: 刚开始 (<20%)

### 论文产出机制
- 每1分钟更新研究进度
- 研究进度达到100%时自动产出论文
- 产出的论文自动添加到论文管理系统
- 论文主题根据学生专业生成

## 与招募系统集成

- 当在招募面板中招募学生时，会自动添加到学生管理面板
- 新招募的学生会立即出现在学生列表中
- 招募天数从0开始计算

## 文件结构

- `student_management_panel.tscn` - 主面板场景
- `student_management_panel.gd` - 主面板脚本
- `student_item.tscn` - 单个学生项目场景
- `student_item.gd` - 单个学生项目脚本

## 快捷键

- `O` - 招募面板
- `P` - 论文管理面板
- `S` - 学生信息管理面板

## 数据流

1. 在招募面板招募学生
2. 学生自动添加到学生管理面板
3. 学生开始产出论文（每分钟）
4. 在论文管理面板中投递论文
5. 收集产出的论文供投递使用
