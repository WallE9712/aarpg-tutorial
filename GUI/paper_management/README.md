# 论文管理面板

## 功能说明

论文管理面板是一个用于管理学生论文的UI界面，与recruit_panel保持相同的尺寸和风格。

## 使用方法

- **打开/关闭面板**: 按 `P` 键
- **查看论文详情**: 点击论文项目
- **选择论文投递**: 点击未投递的论文（会高亮显示）
- **投递论文**: 点击"投递选中论文"按钮

## 论文状态

- **未投递** (灰色): 论文尚未提交
- **已录用** (绿色): 论文已被期刊/会议录用
- **被拒绝** (红色): 论文被期刊/会议拒绝

## 论文信息

每篇论文包含以下信息：
- 论文标题
- 学生姓名
- 期刊/会议名称
- 提交日期
- 状态
- 影响因子（仅对已投递的论文）

## 文件结构

- `paper_management_panel.tscn` - 主面板场景
- `paper_management_panel.gd` - 主面板脚本
- `paper_item.tscn` - 单个论文项目场景
- `paper_item.gd` - 单个论文项目脚本

## 投递功能

- **选择论文**: 只有状态为"未投递"的论文才能被选择
- **投递结果**: 随机决定（30%被录用，70%被拒绝）
- **视觉反馈**: 选中的论文会以蓝色高亮显示
- **状态更新**: 投递后论文状态会立即更新
- **影响因子**: 被录用的论文会获得随机影响因子（1.0-10.0）

## 模拟数据

系统会自动生成10篇模拟论文，包含：
- 随机分配的论文标题
- 随机分配的期刊/会议名称
- 随机分配的学生姓名
- 随机分配的状态（30%未投递，40%已录用，30%被拒绝）
- 随机的影响因子（1.0-10.0）
